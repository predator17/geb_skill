# Unit: Typographical Number Theory (TNT) Introduction
**PDF pages**: 248+
**Printed folio**: ~204

## Key terms
- **TNT**: Formal system that expresses number theory via typographical rules.
- **numerals**: S0, SS0, SSS0, ... representing natural numbers.
- **atoms**: Equality statements such as SO=SSO.
- **free variable**: Variable not bound by a quantifier; formula is open.

## Concept unpacking
- TNT embeds the Propositional Calculus and adds number-theoretic primitives (successor, addition, multiplication, quantifiers).
- The goal is to capture number theory so that Gödel's self-referential construction can be carried out inside the system.

## Author-stated intentions
- To present a formal system with the capacity for wrapping around (self-reference via Gödel numbering).
- Keep formal TNT distinct from informal number theory (N).

## Structural notes
- Well-formedness is defined recursively from atoms and formation rules.
