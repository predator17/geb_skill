# Unit: pq-system
**PDF pages**: 90–93+
**Printed folios**: ~46–49

## Key terms
- **pq-system**: Formal system with symbols p, q, - ; infinite axioms via schema.
- **axiom schema**: x p - q x - where x is hyphens only.
- **isomorphism**: Mapping that induces meaning (addition).

## Concept unpacking
- Decision procedure via addition of hyphen lengths.
- Meaning arises from isomorphism, not from the symbols themselves.

## Author-stated intentions
- Demonstrates how form can acquire meaning despite itself.
